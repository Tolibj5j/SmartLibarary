# SmartLibrary

Maktab, litsey, kollej va OTM kutubxonalari uchun kitob hisobi, berish-qaytarish, qidiruv, sharh va hisobotlarni avtomatlashtiradigan tizim. Veb-sayt (xodimlar uchun) va Telegram bot / Mini App (o'quvchilar uchun).

## Holat

Loyiha **loyihalash bosqichida**. Hozircha ishlaydigan server kodi yo'q, faqat bosiladigan prototip va hujjatlar bor.

## Papkalar

| Papka | Nima bor |
|---|---|
| `prototype/` | Bosiladigan prototip (`index.html`): super-admin, admin, kutubxonachi va o'quvchi ekranlari. Brauzerda oching. |
| `demo/` | Telefon kamerasi bilan shtrix-kod skaneri demosi (`skaner.html`). |
| `docs/` | Rollar, tariflar va qabul qilingan qarorlar. |
| `concept/` | Dastlabki loyiha konsepsiyasi va SWOT tahlili. |

## Rejalashtirilgan texnologiyalar

Django (REST), PostgreSQL, Telegram bot va Mini App, Docker. Batafsil: `docs/QARORLAR.md`.

## Eslatma

Prototipdagi barcha ma'lumotlar (muassasalar, ismlar, telefonlar, narxlar) **uydirma**, test uchun yaratilgan. Haqiqiy shaxsiy ma'lumotni bu repozitoriyga qo'shmang.
