# Rollar va ruxsatlar

Boshqaruv adminda, kundalik ish kutubxonachida. Super-admin faqat platformani boshqaradi va muassasa ichidagi shaxsiy ma'lumotni ko'rmaydi.

| Vazifa | Admin | Kutubxonachi |
|---|:---:|:---:|
| Kitob berish va qaytarish | - | + |
| Katalog (kitob qo'shish, tahrirlash) | - | + |
| O'quvchilarni ro'yxatga olish, karta va bot kodi | - | + |
| Band qilish va navbat | - | + |
| Qarzdorlarni ko'rish | + | + |
| Jarima / ballni ko'rish | + | + |
| Pul to'lovini qayd etish | - | + |
| Jarima / ballni kechirish | + | - |
| Kitobni hisobdan chiqarish | + | - (so'rov yuboradi) |
| Sharhlarga ruxsat berish, yashirish | - | + |
| Xodimlar, sozlamalar, obuna | + | - |
| To'liq hisobotlar, reyting, jurnal | + | - |
| O'z kundalik ko'rsatkichlari (sonlar) | + | + |

Kichik muassasada bitta odam ikkala rolni bajaradi: bitta akkauntga ikkala rol beriladi (hali prototipda yo'q).

Super-admin: muassasalar, tariflar, to'lovlar, platforma statistikasi, jurnal, super-adminlar, murojaatlar. Muassasa ichidagi o'quvchi ma'lumotlarini ko'rmaydi, faqat umumiy sonlarni.
